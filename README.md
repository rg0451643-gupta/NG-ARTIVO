# NG ARTIVO

A professional graphic design and creative portfolio website developed to showcase digital posters, creative designs, and graphic design services.

## Features

- Responsive and user-friendly website
- Creative graphic design portfolio
- Services section
- User registration form
- Admin panel
- Registered user management
- MongoDB database integration
- Session-based admin authentication

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
- Git & GitHub
